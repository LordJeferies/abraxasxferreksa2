## Publicar
Necesitas Git y GitHub CLI (https://cli.github.com/). Abre Terminal y ejecuta `bash publicar.command` desde esta carpeta. El asistente permite iniciar sesión en GitHub como LordJeferies, crea el repositorio público abraxasxferreksa2 si no existe y configura Pages desde main, raíz. No fuerza sobrescrituras de una rama existente. Si el repositorio ya tiene commits distintos, detiene la subida para que puedas integrar los archivos desde un clon actualizado.

URL prevista, todavía no verificada como publicada: https://lordjeferies.github.io/abraxasxferreksa2/

La portada usa una imagen integrada para conservar perspectiva, piso y sombras. Se retiró la composición por capas del personaje. El logo frontal se entrega como PNG transparente. Los locales y horarios se transcribieron de las capturas facilitadas por el usuario. Los enlaces Maps son búsquedas por nombre y dirección, no coordenadas verificadas.
